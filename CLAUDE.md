# Offerly — правила для агента разработки

Проект Юрия Самусенко (ИНТЕРПРО). Язык общения и документов — русский; тексты интерфейса — русские, английский только внутри учебного содержимого. Концепт — `docs/concept.md`, задачи — `ROADMAP.md`, состояние цикла — `STATE.json`.

## Цикл одного запуска
1. Прочитать `ROADMAP.md` и `STATE.json`. Если в `STATE.json` есть незакрытый дефект — сначала он.
2. Взять первую незакрытую задачу, реализовать с тестами. Одна задача за запуск.
3. `npm test` и `npm run build` должны проходить. Не прошло и не починилось — записать дефект в `STATE.json`, не коммитить.
4. Коммит с понятным сообщением, push в `main`. Деплой делает Actions.
5. Подождать деплой (`gh run watch` или опрос `gh run list`), проверить `https://offerly-c8b.pages.dev/api/health` и затронутые экраны.
6. Отметить задачу в `ROADMAP.md`, дописать `CHANGELOG.md`, обновить `STATE.json` (включая commit и статус деплоя), запушить.
7. Отправить короткое сообщение: что сделано, что сломалось, что следующее.

## Ограничители
- Миграции, меняющие или удаляющие существующие данные, удаление таблиц, смена схемы оплаты, публикация в магазины — только после подтверждения Юрия: остановиться и спросить.
- Новые миграции — только добавлением файлов `migrations/NNNN_*.sql`, старые не править.
- Версия в `package.json` и `VERSION` в API: исправление — patch, новая возможность — minor.
- Секреты не коммитить; ключи пользователей хранить только зашифрованными.

## Стиль
- Интерфейс по дизайн-проекту: графит #141C2B, бумага #F6F3EE, янтарь #F2A541 (прогресс), мята #3FBF9F (верно), коралл #E0655B (ошибка); Manrope для заголовков, Inter для текста, JetBrains Mono для правок. Без эмодзи, без маскота, без конфетти.
- Тон тренера — взрослый, прямой, поддерживающий. Ошибки называть прямо, одной строкой объяснения.
- Ничего не выдумывать в учебном содержимом: эталоны и рубрики хранить в D1, проверку ответов вести сравнением с эталоном.

## Особенности окружения
- Логи шагов Actions из облачной сессии не читаются (прокси); всё, что нужно увидеть, выводить аннотациями `::notice title=…::` в одну строку — они видны в `gh run view`.
- Прямой `curl` к `*.pages.dev` из облака запрещён, проверять живой адрес через WebFetch.
- Репозиторий в новой сессии подключать через add_repo (push), клонировать в `/home/claude/offerly`.
